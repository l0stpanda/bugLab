# Task: Fix the Median Function

## Objective
Fix the `median(numbers)` function in solution.py.

## Requirements
1. `numbers` is a list of ints or floats, which may be negative.
2. If the list has an odd number of items, return the middle value
   once the list is sorted.
3. If the list has an even number of items, return the mean of the
   two middle values. For example, `median([1, 2, 3, 4])` is `2.5`.
4. If the list is empty, raise `ValueError`.
5. Do not modify the input list.

Do not change the function name or its arguments.

## Completion
`run_tests` runs some of the tests used for grading. Your
solution will also be graded against additional tests that
you cannot run.

Only modify solution.py.
