# Task: Fix the Average Calculator

## Objective
Fix the `calculate_average(numbers)` function in solution.py.

The function should return the arithmetic mean of a
non-empty list of numbers.

## Requirements
- Support positive and negative numbers.
- Support decimal values.
- Return a numeric result.
- Do not change the function name or its arguments.

## Completion
`run_tests` runs some of the tests used for grading. Your
solution will also be graded against additional tests that
you cannot run.

Only modify solution.py.
